1. Setup a default AWS EC2 instance (Ubuntu, t3.medium, 30GB of storage, for the DuckDB file)
2. Get a .pem file for the instance
3. chmod 400 ~/path/to/your-key.pem
4. ssh -i ssh -i ~/Documents/parcel-keypair.pem ubuntu@54.160.148.39
Run:
# Update packages
1. sudo apt update && sudo apt upgrade -y
2. sudo apt install -y python3 python3-pip python3-venv
3. mkdir -p ~/app
To transfer files, run:
	rsync -avz -e "ssh -i ~/Documents/parcel-keypair.pem" \
	--exclude '__pycache__' \
	--exclude '*.pyc' \
	--exclude 'venv' \
	--exclude 'nycdb.duckdb' \
	--exclude 'logs' \
	--exclude '*.log' \
	--exclude '.git' \
	--exclude '.github' \
	--exclude 'aws' \
	./ ubuntu@54.160.148.39:~/app/

To upload the duckdb
scp -i ~/Documents/parcel-keypair.pem nycdb.duckdb ubuntu@54.160.148.39:~/app/

To start the server:

ssh -i ~/Documents/parcel-keypair.pem ubuntu@54.160.148.39
cd ~/app
source venv/bin/activate
tmux new -s server
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

To leave the server running in the background:
detach with Ctrl+B, then D.

To reattach to the server session (if you need to check logs, etc.):
tmux attach -t server

To stop the server:
tmux attach -t server
Ctrl+C

To setup HTTPS:
1. Get a free domain from DuckDNS
2. In the instance, run:
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update
sudo apt install -y caddy
3. sudo nano /etc/caddy/Caddyfile
```

Replace the contents with:
parcel-api.duckdns.org {
    reverse_proxy localhost:8000
}

sudo systemctl restart caddy

Make sure EC2 has Https open (443)
